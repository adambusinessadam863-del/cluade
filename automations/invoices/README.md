# חילוץ חשבוניות לטבלה (התחלה)

**מצב: ליבה כתובה ונבדקה על לוגיקה בלבד. לא הורצה מול Claude אמיתי ולא על חשבוניות אמיתיות.**

```bash
npm i @anthropic-ai/sdk
export ANTHROPIC_API_KEY=...
node cli.js --dir ./חשבוניות --out invoices.csv
```
- `extract.js`: PDF או תמונה → JSON מובנה (`claude-opus-5-5`, פלט מובנה, מאמץ נמוך).
- `validate.js`: ח.פ, תאריך, סכומים מול מע״מ (18%), מספר הקצאה מעל סף (ברירת מחדל ₪5,000, **בדקו מול רשות המסים**), כפילויות, ודאות.
- `csv.js`: אקסל בעברית, בלי הזרקת נוסחאות.
- בדיקות: `node test.js`.

## מה צריך לפני מכירה
1. הרצה על 20–30 חשבוניות אמיתיות ומדידת דיוק.
2. חיבור לתוכנת הנה״ח של הלקוח.
3. תור בדיקה נוח במקום CSV.
4. מדידת עלות לחשבונית.

**פרטיות:** חשבוניות כוללות מידע עסקי של צדדים שלישיים. קבלו הסכמה מהלקוח ובדקו איפה הקבצים נשמרים.
