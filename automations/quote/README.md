# הצעת מחיר מיידית

- **כלי בדפדפן:** `web/index.html` (בלי התקנה, עובד מהטלפון). בוחרים סוג עסק, ממלאים פרטים, מקבלים הצעה מעוצבת, ושולחים בוואטסאפ, מדפיסים ל-PDF או מעתיקים טקסט. ההגדרות נשמרות בדפדפן.
- **שורת פקודה:** `node cli.js --preset movers --input samples/movers-input.json --biz samples/biz.json --out out --pdf` (PDF דורש `playwright`).
- **בדיקות:** `node test.js`. **דוגמה:** `samples/sample-quote-movers.html` ו-`.pdf`.

## התאמה ללקוח
1. מקבלים את המחירון של העסק.
2. עורכים את `presets.js`: שדות הטופס, מחירי יחידה, תנאים. **המחירים שם הם דוגמאות** ויש להחליף אותם.
3. מארחים את התיקייה כולה (GitHub Pages, Netlify). הלקוח מכניס את הקישור למסך הבית של הטלפון.
4. מע״מ: ברירת מחדל 18% (בדקו את השיעור הנוכחי). אפשר לכבות בכלי.

## חיבור למענה לידים
`presets.js` כולל `movers.fromLead()` שממיר תשובות מתהליך השיחה של ההובלות (`../../whatsapp-followup`) לשדות ההצעה. מומלץ כחבילה.

## מגבלות
- תמחור לפי חוקים קבועים, לא לפי הערכה חופשית. עבודות מורכבות צריכות הצעה ידנית.
- ההצעה אינה מסמך משפטי. הוסיפו תנאים לפי הצורך.
- לא מייצר חשבונית מס.
