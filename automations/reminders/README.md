# תזכורות תורים והחזרת שעות

הקוד: `index.js`. בדיקות: `node test.js`. הדמיה: `demo.html`.

## מה עושה
- מייבא תורים מקובץ CSV (עמודות: `שם`, `טלפון`, `מועד`, `שירות`, או באנגלית). מנקה טלפונים ומתאריכים (`2026-10-12 17:00` או `12/10/2026 17:00`, שעון ישראל כולל מעבר שעון קיץ).
- שולח תזכורת 24 שעות לפני (תבנית מאושרת עם שלושה כפתורים) ותזכורת שנייה 3 שעות לפני רק למי שלא אישר.
- לא שולח בלילה (21:00–08:00) ולא בשבת (הערכה: שישי מ-15:00 עד שבת 20:00).
- אישור / ביטול / הזזה: בכפתור או במילים ("1", "אישור", "ביטול"). מעדכן סטטוס ומתריע לבעל העסק בטלגרם.
- ביטול: מציע את השעה לראשון ברשימת ההמתנה. תפיסה בלחיצה. ההצעה פגה אחרי 30 דקות והבאה בתור. בלי מי שמחכה, בעל העסק מקבל התראה.
- חזרה מביטול ("אישור" אחרי ביטול) אפשרית כל עוד השעה לא נתפסה.
- סיכום ערב לבעל העסק על מחר.
- "הסר" עוצר הכל.

## הפעלה
```bash
cp .env.example .env     # ממלאים
APPOINTMENTS_CSV=sample-appointments.csv node --env-file=.env index.js
```
כתובת ה-Webhook ב-Meta: `https://<הדומיין>/webhook`. נקודות ניהול (עם `ADMIN_TOKEN`): `GET /stats`, `POST /import` (גוף: CSV).

## תבניות Meta לאישור (עברית, עם משתנים)
**`appointment_reminder_v1`**, גוף: `שלום {{1}}, תזכורת ל{{3}} ב{{2}}. נשמח לאישור הגעה 🙏`. כפתורי "תשובה מהירה": `מאשר/ת`, `מבטל/ת`, `להזיז`.
**`slot_available_v1`**, גוף: `שלום {{1}}, התפנתה שעה אצלנו: {{2}}. ההצעה שמורה לך ל-{{3}} דקות.`. כפתורים: `אני לוקח/ת`, `לא תודה`.
Meta מחליטה על הקטגוריה (שירות או שיווק) וזה משפיע על המחיר.

## מגבלות
- אחסון בקובץ JSON. מתאים לעשרות או מאות תורים בחודש.
- כפתורי התבנית מתקבלים כהודעה מסוג `button` בתוך ה-Webhook. זה נכתב לפי התיעוד שאני מכיר ונבדק רק מול מדמה, בדקו מול Meta.
- אין סנכרון אוטומטי עם יומן גוגל. הייבוא הוא CSV (אפשר לייצא מגוגל שיטס).
- חיבור שאינו אישי: ההצעה לרשימת המתנה היא הודעה יזומה לאדם שאישר לשמור אותו ברשימה. הוסיפו לו הסכמה בטופס ההרשמה.
