# הדגמת מעקב לידים בוואטסאפ

פותחים את `index.html` בדפדפן. בוחרים תחום (נהיגה / שיפוצים / פילאטיס / הובלות), מקלידים את שם העסק של הלקוח, ולוחצים כמו לקוח אמיתי.

- `flows.js`: השאלות, הודעות המעקב והניקוד לכל תחום (ערוכים בעברית).
- `engine.js`, `style.css`, `index.html`: הדמיית השיחה.
- `demo.html?b=reut|haon|yadofek`: עמוד הדמיה מלוטש לכל עסק (שני טלפונים, ותרשים "איך זה בנוי").
- `prospects.js`, `prospects.md`: שלושת העסקים (רעות, האון, יד אופק) ומבחן ההודעה (פנימי).
- `playbook.md`: איך מוכרים, תמחור, עלויות, ובנייה מאפס עד עסק עובד.
- `server/`: שרת Node אמיתי (webhook של Meta, תהליך השיחה, מעקבים, התראות). `npm test` מריץ 9 בדיקות מול וואטסאפ מדומה.
- `pitches.md`: איך מוצאים עסקים, תמחור, שלושה מיילים בעברית וכללי חוק.

זו הדגמה בלבד. היא לא מחוברת לוואטסאפ אמיתי.
