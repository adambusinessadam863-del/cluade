# הדגמת מעקב לידים בוואטסאפ

פותחים את `index.html` בדפדפן. בוחרים תחום (נהיגה / שיפוצים / פילאטיס), מקלידים את שם העסק של הלקוח, ולוחצים כמו לקוח אמיתי.

- `flows.js`: השאלות, הודעות המעקב והניקוד לכל תחום (ערוכים בעברית).
- `engine.js`, `style.css`, `index.html`: הדמיית השיחה.
- `pitches.md`: איך מוצאים עסקים, תמחור, שלושה מיילים בעברית וכללי חוק.

זו הדגמה בלבד. היא לא מחוברת לוואטסאפ אמיתי.
